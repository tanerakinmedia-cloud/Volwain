VOLWAIN - YENI PROJE

Bu proje, Volwain masaustu uygulamasinin ilk arayuz iskeletidir.
Windows EXE, GitHub Actions ile otomatik olusturulur.

ONEMLI: Bu paket su anda yerel arayuz prototipidir. Gercek internet uzerinden cok kullanicili ses ve sohbet altyapisi henüz eklenmemistir. Mikrofon seviye göstergesi yerel mikrofonu ölçer; uzak kullanıcıların sesi/oda eşleştirmesi çalışır durumda değildir.

Kurulum: GitHub deposuna bu klasorun icerigini yukleyin. Actions sekmesindeki Volwain Windows Kurulum Dosyasi is akisi tamamlaninca Volwain-Windows-Setup artifact'ini indirin.
